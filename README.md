# Sense of Space

One-page website for Sense of Space, a decluttering and organising service in Plymouth, Devon.

Plain static site: `index.html` plus the `assets` folder. No build step.

## Things to update before going live
- **Phone number**: search `index.html` for `07000 000000`.
- **Facebook link**: search for `https://www.facebook.com/`.
- **Booked slots**: currently example data. Search for `example bookings`.
- **Deposit payments**: search for `PAYMENT`. Paste a payment link and set `enabled: true`.
- **School holidays**: the `HOLS` list (Plymouth City Council dates to Jan 2028).

## Deploy
Import this repository into Vercel as a new project. Framework preset: **Other**. No build command, output directory left blank.
